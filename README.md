# งานเหมาะวัยเก๋า

เว็บไซต์รวบรวมงานที่เหมาะกับสุขภาพผู้สูงอายุ เลือกจังหวัด ช่วงอายุ และข้อจำกัดทางร่างกายได้

## วิธีเผยแพร่เป็นลิงก์สาธารณะด้วย GitHub Pages
1. ไปที่ github.com แล้วสร้าง Repository ใหม่ ตั้งเป็น Public
2. กด "uploading an existing file" แล้วลากไฟล์ index.html และ README.md ใส่ แล้วกด Commit changes
3. ไปที่ Settings > Pages > Source เลือก "Deploy from a branch" > Branch: main > Folder: /(root) > Save
4. รอ 1-2 นาที ลิงก์จะเป็น https://ชื่อผู้ใช้.github.io/ชื่อ-repository/
